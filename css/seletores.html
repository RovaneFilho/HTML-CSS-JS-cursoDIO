Seletores CSS

Bem-vindo!

No Css nós possuimos os seletores por ID

  • Seletor por Tipo: Busca elementos por uma tag HTML especifica
  • Seletor por ID(#):Busca elementos através do atributo "id"
  • Seletor por Classe(.):Busca elementos atraves do atributo "Classe"
  • Seletor Universal (*):Seleciona todos os elementos HTML
  • Seletor de Atributo ([atrib]):Seleciona elementos que possuem um atributo especifico em nosso documento HTML e conseguimos tambem buscar atributos com o valor especifico
